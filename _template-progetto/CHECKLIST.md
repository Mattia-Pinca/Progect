# Checklist pre-consegna

Da spuntare prima di consegnare al cliente.

## Funzionalità
- [ ] Tutti i requisiti del `BRIEF.md` sono soddisfatti
- [ ] Casi limite ed errori gestiti
- [ ] Niente funzionalità incomplete o "TODO" rimasti

## Test
- [ ] Il codice gira senza errori
- [ ] Testato con dati/scenari realistici
- [ ] Testato su ambiente/versione richiesti dal cliente

## Qualità
- [ ] Codice leggibile e commentato dove serve
- [ ] Nessuna credenziale o dato sensibile nel codice consegnato
- [ ] File inutili/temporanei rimossi

## Consegna
- [ ] Materiale finale pronto in `consegna/`
- [ ] Istruzioni di installazione/uso scritte e chiare
- [ ] Messaggio di consegna per il cliente pronto
- [ ] (Se previsto) breve spiegazione di cosa è stato fatto

## Dopo la consegna
- [ ] Stato aggiornato nel `README.md` del progetto
- [ ] Eventuali revisioni richieste annotate nel `BRIEF.md`
