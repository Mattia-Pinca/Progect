# Gig per Fiverr — pronti da incollare

Tre gig su servizi a basso rischio e alta resa. Per ognuno: titolo, categoria,
tag, descrizione, pacchetti di prezzo, FAQ e requisiti da chiedere al cliente.

I prezzi sono di partenza per costruire le prime recensioni: una volta presa
quota, si possono alzare. Fiverr trattiene una commissione (~20%), tienine
conto nei prezzi.

## GIG 1 — Fix di bug e troubleshooting

**Titolo (max 80 caratteri):**
> I will fix bugs and errors in your website, script or web app

**Categoria:** Programming & Tech → Website Development → Bug Fixes
(in alternativa: Software Development)

**Tag di ricerca (5):** `bug fix`, `debugging`, `error fix`, `wordpress fix`, `javascript`

**Descrizione:**
```
Hai un bug, un errore o qualcosa che non funziona come dovrebbe? Lo sistemo io.

Lavoro su siti web, script e piccole web app. Identifico la causa del
problema, lo correggo e ti spiego cosa è successo, così non si ripresenta.

✅ Cosa posso sistemare:
• Errori e bug in PHP, JavaScript, Python, HTML/CSS
• Problemi su siti WordPress (temi, plugin, errori 500, schermata bianca)
• Script che si bloccano o danno risultati sbagliati
• Layout rotti, elementi che non funzionano
• Errori di console e funzionalità non funzionanti

✅ Come lavoro:
1. Mi mandi il problema (e l'accesso al codice/sito se serve)
2. Trovo la causa e la correggo
3. Testo la soluzione
4. Ti consegno il fix + una breve spiegazione

💬 Non sei sicuro che il tuo problema rientri? Scrivimi prima di ordinare,
ti rispondo e ti dico se posso aiutarti e quanto tempo serve.
```

**Pacchetti:**

| | Basic | Standard | Premium |
|---|---|---|---|
| Nome | Quick Fix | Standard Fix | Complex Fix |
| Prezzo | €15 | €40 | €90 |
| Descrizione | 1 bug semplice e isolato | Fino a 3 bug o 1 problema medio | Bug complesso / più problemi collegati |
| Consegna | 2 giorni | 3 giorni | 5 giorni |
| Revisioni | 1 | 2 | 3 |

**FAQ:**
- *Devo darti accessi?* — Solo se necessario per riprodurre il problema. Meglio
  un accesso temporaneo o di staging; cambia le password dopo la consegna.
- *E se non riesci a sistemarlo?* — Se dopo l'analisi non è risolvibile nel
  pacchetto, te lo dico subito e ti rimborso.

**Requisiti da chiedere al cliente (Requirements):**
- Descrizione del problema e come riprodurlo
- Accesso al codice/sito (o i file rilevanti)
- Cosa dovrebbe succedere invece (comportamento atteso)

**Titolo:**
> I will write a Python script to automate your repetitive tasks

**Categoria:** Programming & Tech → Software Development → Scripting

**Tag di ricerca (5):** `python script`, `automation`, `web scraping`, `excel automation`, `data scraping`

**Descrizione:**
```
Perdi tempo con compiti ripetitivi? Te li automatizzo con uno script Python
fatto su misura.

✅ Cosa posso automatizzare:
• Raccolta dati da siti web (web scraping)
• Elaborazione e pulizia di file Excel / CSV
• Rinominare, ordinare o convertire file in massa
• Invio automatico di email o report
• Connessione tra servizi tramite API
• Qualsiasi compito noioso e ripetitivo che fai a mano

✅ Cosa ricevi:
• Uno script Python funzionante e commentato
• Istruzioni semplici per eseguirlo (anche se non sei tecnico)
• Una breve spiegazione di come funziona

💬 Raccontami cosa fai a mano oggi e ti dico come automatizzarlo. Scrivimi
prima di ordinare per definire bene il lavoro.
```

**Pacchetti:**

| | Basic | Standard | Premium |
|---|---|---|---|
| Nome | Mini Script | Standard Script | Advanced Script |
| Prezzo | €20 | €55 | €120 |
| Descrizione | Script semplice, 1 compito | Script con più passaggi / scraping medio | Automazione complessa, più fonti/API |
| Consegna | 2 giorni | 4 giorni | 6 giorni |
| Revisioni | 1 | 2 | 3 |

**FAQ:**
- *Funziona sul mio computer?* — Sì, ti do le istruzioni per Windows/Mac. Se
  preferisci, posso renderlo eseguibile senza installare nulla.
- *Lo scraping è legale?* — Raccolgo dati pubblici e rispetto i termini dei

**Requisiti da chiedere al cliente:**
- Descrizione del compito da automatizzare (con un esempio reale)
- File o siti coinvolti
- Sistema operativo (Windows / Mac / Linux)
- Formato del risultato desiderato

## Consigli per la pubblicazione

- **Immagine del gig:** usa un'immagine chiara con un titolo leggibile. Puoi
  crearla gratis con Canva. Conta più di quanto sembri.
- **Prezzi iniziali bassi:** servono a ottenere le prime recensioni. Dopo 3-5
  recensioni a 5 stelle, alza i prezzi.
- **Rispondi veloce:** Fiverr premia chi risponde in fretta ai messaggi.
- **Niente over-promise:** consegna sempre ciò che prometti, testato. Una
  recensione negativa all'inizio pesa tantissimo.
- **Sempre "scrivimi prima di ordinare":** ti permette di valutare il lavoro
  ed evitare ordini impossibili o fuori ambito.
```
