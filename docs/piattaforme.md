# Piattaforme per trovare lavori IT una tantum

Riferimento rapido delle piattaforme dove cercare commesse.

## Generaliste (forte sezione IT)

| Piattaforma      | Modello                     | Note |
|------------------|-----------------------------|------|
| Upwork           | Offerte su progetti, a ore o fisso | La più grande, tanta concorrenza |
| Fiverr           | "Gig" a pacchetto, prezzo fisso    | Ottimo per task piccoli e definiti |
| Freelancer.com   | Offerte / contest           | Budget variabili |
| Guru             | Offerte su progetti         | Simile a Upwork |
| PeoplePerHour    | A ore o a progetto          | Popolare in Europa/UK |
| Toptal           | Selezione rigorosa, senior  | Progetti di qualità/budget alto |

## Tipi di lavoro più adatti a noi (alta resa, basso rischio)

- Fix di bug e troubleshooting (problema definito, risultato verificabile)
- Script di automazione (Python/Bash)
- Personalizzazioni WordPress / temi / plugin
- Scraping e raccolta dati
- Pulizia/trasformazione dati, fogli Excel/Sheets con formule
- Piccole web app / landing page
- Documentazione tecnica, README, guide
- Integrazioni tra servizi via API
